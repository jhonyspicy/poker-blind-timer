# signage-display デルタ: セッション限定のストラクチャー上書き

## ADDED Requirements

### Requirement: セッション限定のストラクチャー上書き
サイネージは、リモコンからの `STRUCTURE_UPDATE` コマンド(ストラクチャー全量)を受信したとき、以下を検証し、すべて満たす場合のみセッション限定の上書き(`structureOverride`)として採用しなければならない(MUST):

1. トーナメントが終了(`finished`・優勝確定)していないこと
2. 受信ストラクチャーの先頭から解決済みの現在項目までの区間が、現在の実効ストラクチャーの同区間と項目単位で一致すること(進行中・通過済みの項目を変更していないこと)。境界判定は適用時点のサイネージのタイマー解決結果で行う(MUST)。開始前(`waiting`)はこの制約を課さない
3. ストラクチャー検証ルールを満たすこと(ブラインド 1 つ以上、レイトレジ締切マーカー 1 つまで、継続時間が正、SB / BB が正、Ante が 0 以上)

採用後は上書き後のストラクチャーを実効ストラクチャーとし、タイマー進行・レベル切替・NEXT BREAK / LATE REGISTRATION などの表示・状態スナップショットのすべてに適用しなければならない(MUST)。保存済みのトーナメント設定(configs)は変更してはならない(MUST NOT)。

検証に失敗した場合はセッションを変更せず、現在の状態スナップショットを配信し直さなければならない(MUST。リモコンが競合を検知して再同期するため)。

#### Scenario: 上書きの適用
- **WHEN** レベル 3 進行中に、レベル 4 以降だけを変更した `STRUCTURE_UPDATE` を受信する
- **THEN** 上書きが採用され、以降のレベル進行と NEXT BREAK 等の表示が新しいストラクチャーに従い、進行中のレベル 3 の残り時間は変化しない

#### Scenario: 進行中の項目に触れる編集の拒否
- **WHEN** レベル 3 進行中に、レベル 3 の継続時間を変更した `STRUCTURE_UPDATE` を受信する
- **THEN** 上書きは採用されず、現在の状態スナップショットが配信し直される

#### Scenario: 自動遷移との競合の拒否
- **WHEN** リモコンがレベル 3 進行中の表示をもとにレベル 4 を変更したが、コマンド到達時にはレベル 4 へ自動遷移していた
- **THEN** プレフィックス一致の検証に失敗して上書きは採用されず、現在の状態スナップショットが配信し直される

#### Scenario: 保存済み設定の不変
- **WHEN** 上書きが採用された後、同じ設定で新しいトーナメントを開始する
- **THEN** 新しいトーナメントは保存済み設定の元のストラクチャーで開始される

### Requirement: ストラクチャー上書きの永続化と復元
採用されたストラクチャー上書きは進行中セッションの一部として IndexedDB に保存し、サイネージのリロード後も復元して実効ストラクチャーとして使い続けなければならない(MUST)。上書きを持たない旧セッションデータは「上書きなし」として扱わなければならない(MUST)。

#### Scenario: リロード後の復元
- **WHEN** ストラクチャー上書きの採用後にサイネージをリロードする
- **THEN** 上書き後のストラクチャーでタイマーが復元され、レベル・残り時間・以降の進行が一致する
