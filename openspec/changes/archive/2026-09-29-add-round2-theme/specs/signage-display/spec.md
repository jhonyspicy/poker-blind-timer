# signage-display 差分: Round2 テーマの追加

## ADDED Requirements

### Requirement: Round2 テーマの表示と演出実装

サイネージは、選択可能なテーマとして Round2(id: `round2`、ブルー×シアンの店舗ブランドデザイン)を提供しなければならない(MUST)。Round2 は待機 / タイマー / ブレイク / 優勝の各局面を専用画面として表示し、タイマー画面の表示項目・K 表記・一時停止演出・待機画面の表示内容などテーマ共通の要件をすべて満たさなければならない(MUST)。ただしレベルアップ演出は中央パネルの発光ブーストのみとし、「LEVEL UP」の文字・値のロールは表示しない。一時停止は暗転 + PAUSED 帯 + カウントダウンの点滅で表示する。

Round2 は全画面演出(トーナメント開始・インマネ・HEADS UP・優勝)を表示せず、イベントに対して即座に終了を返さなければならない(MUST。終了 = 合図として扱われ、開始は即座にタイマーが起動し、優勝は即座にタイマー停止・優勝画面へ遷移する)。

タイマー画面の背景はテーマ素材のループ動画(`videos/timer-background.webm`)、待機・優勝画面の背景はテーマ素材の画像とする。素材が未配置の場合は背景なしで表示する。

ブレイク画面は、左側にブレイク残り時間・進捗バー・PLAYERS / AVERAGE STACK・NEXT BLINDS を、右側に広告カルーセル(テーマ素材の広告画像と、設定のプライズから生成するプライズ一覧スライド)を表示しなければならない(MUST)。ブレイク残り 60 秒以下では、カルーセルの代わりに「まもなく再開」画像を表示する。

#### Scenario: Round2 テーマでの表示

- **WHEN** テーマに Round2 を選択した設定でサイネージを開く
- **THEN** Round2 の画面一式で表示され、タイマー画面には共通要件の全項目が表示される

#### Scenario: Round2 の開始

- **WHEN** Round2 テーマでリモコンから開始操作を受信する
- **THEN** 演出は表示されず、即座にタイマー画面へ遷移してカウントダウンが始まる

#### Scenario: Round2 のブレイク終盤

- **WHEN** Round2 テーマでブレイクの残り時間が 60 秒以下になる
- **THEN** 広告カルーセルが「まもなく再開」画像に切り替わる

#### Scenario: Round2 の一時停止

- **WHEN** Round2 テーマのタイマー画面またはブレイク画面で一時停止する
- **THEN** 画面が暗転して PAUSED 帯が表示され、再開で解除される
