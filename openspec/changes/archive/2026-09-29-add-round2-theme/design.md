# Design: Round2 テーマ

## Context

テーマ機構(Root 1 個 + 素材ディレクトリ + 宣言メタデータ)と、その 2 例目である GILDED が実装済み。Round2 は店舗専用のテーマで、Claude Design のモック 4 画面が提供されている。モックには全画面演出・一時停止・レベルアップのデザインは含まれていない。

## Decisions

### D1: GILDED と同じ構成で、テーマディレクトリを独立させる

`src/pages/signage/themes/round2/` を新設し、他テーマのコンポーネントを import しない(1920×1080 ステージの scale フック、等幅数字なども round2 内に持つ)。共有するのはドメイン層と共有サイネージ層(`../events`, `../preload`, `..` の型)のみ。

### D2: 全画面演出は表示しない

モックに演出デザインが無いため、4 イベントすべてで演出を表示せず即座に `onDone` を返す(終了 = 合図として扱われ、開始はその場でタイマー起動、優勝は即座に優勝画面へ遷移)。演出を追加するときは Round2 用のオーバーレイを後から足せる。

### D3: 一時停止は PAUSED 帯 + 点滅、レベルアップはパネルの発光のみ

- 一時停止: 画面を暗転し、シアン罫のネイビー帯に「PAUSED」を表示する。止まっている残り時間が読めるよう、帯はカウントダウンの下に置く。背後のカウントダウンはモックの `blink` キーフレームで点滅させる。タイマー・ブレイク両画面で表示する
- レベルアップ: 中央パネルの発光ブースト(約 1.2 秒)のみ。「LEVEL UP」の文字・値のロールは行わない(GILDED と同様の例外)。`prefers-reduced-motion` では行わない

### D4: 背景・広告素材はテーマ素材として先読みする

- 待機: `images/waiting-bg.png`、優勝: `images/champion.png`、タイマー: `videos/timer-background.webm`(muted / loop / autoplay)
- ブレイク: `images/ads/*.png`、プライズスライド背景 `images/ads/prize-bg.png`、再開予告 `images/resume-soon.png`
- すべて `assets` に宣言し、`assetUrl` で解決する。素材が無い(404)場合は背景なし・そのスライドを飛ばす

### D5: ブレイクの広告カルーセル

- スライド順はモック準拠(ドリンク 4 枚 → プライズ一覧 → GTO Wizard)。画像スライドは 8 秒、900ms のクロスフェード
- プライズ一覧スライドは設定のプライズから生成する。自由テキストを「 or 」で行に分け、「30,000PT」のような数値 + 単位は数値を大きく表示する。一覧があふれる場合は下端から上端へスクロールし、スライドの表示時間はスクロール量から算出する
- プライズが 0 件ならプライズスライドを出さない
- ブレイク残り 60 秒以下では「まもなく再開」画像に切り替える
- カルーセルの切り替えは表示用の演出でありタイマー進行には関与しないため、コンポーネント内の setInterval で回す(アンマウント時に解除)

### D6: 長い店名・タイトルは実測で縮める

モックと同様に、店名バッジは文字幅をバッジ内幅に合わせて `scaleX` で伸縮し、タイトルは上限幅を超えたら縮小する。`useLayoutEffect` で `scrollWidth` を実測し、フォント読み込み完了時にも再計測する。
