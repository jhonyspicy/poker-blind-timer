# signage-display 差分: テーマによる表示切替

## ADDED Requirements

### Requirement: テーマによる画面と素材の切り替え
サイネージは、トーナメント設定で選択されたテーマに応じて、画面コンポーネント一式(待機 / タイマー / ブレイク / 優勝と背景・演出)と素材ディレクトリを切り替えて表示しなければならない(MUST)。

- テーマ = 画面コンポーネント一式 + 素材ディレクトリ(動画・効果音・画像)のセットとして定義する。テーマの追加でレイアウト・構成要素・素材を丸ごと差し替えられる仕組みでなければならない(MUST)
- 演出素材はテーマ別ディレクトリ `themes/<テーマ名>/` 配下の `videos/` `sounds/` `images/` から解決しなければならない(MUST)。素材が未配置のイベントをスキップする挙動はテーマ別ディレクトリでも同様に適用する
- 設定のテーマが未指定・不明(アプリが知らないテーマ名)の場合は標準テーマ(`default`)で表示しなければならない(MUST)
- タイマー進行・同期・状態の永続化・素材の先読み・演出動画の再生機構はテーマ間で共有し、テーマはその挙動を変更してはならない(MUST NOT)。テーマが差し替えられるのは見た目と素材のみとする

#### Scenario: 標準テーマでの表示
- **WHEN** テーマ未指定(旧データ含む)または標準テーマの設定でサイネージを開く
- **THEN** 標準テーマの画面一式と `themes/default/` 配下の素材で表示される

#### Scenario: 不明なテーマのフォールバック
- **WHEN** アプリが提供していないテーマ名を持つ設定でサイネージを開く
- **THEN** 標準テーマで表示され、エラーにならない

#### Scenario: テーマ素材の部分配置
- **WHEN** 選択中テーマの素材ディレクトリに一部の動画・効果音しか配置されていない
- **THEN** 配置済みの素材は再生され、未配置のイベントは演出をスキップして画面遷移のみ行われる
