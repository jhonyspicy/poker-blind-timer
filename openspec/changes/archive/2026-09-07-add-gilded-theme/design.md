# Design: GILDED テーマ

## Context

サイネージのテーマ機構は「Root コンポーネント 1 個 + 素材ディレクトリ(public/themes/<id>/)+ 宣言メタデータ」として確立済み(signage-display「テーマによる画面と素材の切り替え」)。現在の提供テーマは `default` のみ。共有層(useSignageController)がタイマー進行・同期・永続化・演出イベント検知・効果音再生・先読みを担い、テーマは確定済みのドメイン状態と演出イベントを受け取って表示だけを組み立てる。

タイマー画面の表示項目・K 表記・レベルアップ / 一時停止演出・待機画面の表示内容はテーマ共通の MUST であり、GILDED も満たす必要がある。

## Goals / Non-Goals

**Goals:**

- 深いグリーン×ゴールドのアール・デコ調ラグジュアリーテーマ「GILDED」(id: `gilded`)を追加する。
  見た目は Claude Design のモック(Tournament Waiting / Tournament Clock + Pause Overlay / Champion Screen)に準拠する
- 動画素材ゼロでも演出込みで完結する(演出は CSS アニメーションで実装)
- テーマ共通 MUST(表示項目・K 表記・レベルアップ / 一時停止演出・スケーリング)をすべて満たす
- 既存テーマ・共有層に変更を加えない(theme.ts / themes/index.ts への登録のみ)

**Non-Goals:**

- 動画演出素材の制作・配置(後日 `public/themes/gilded/` に置けるが本チェンジの範囲外)
- 効果音素材の制作・配置(共有層の仕組みで `themes/gilded/sounds/` に置けば鳴る。初期は未配置 = 無音スキップ)
- WebGL / Three.js 背景(default と差別化し、CSS のみで軽量に実装する)
- 共有層・同期プロトコル・データモデルの変更

## Decisions

### D1: テーマディレクトリは default から独立させる

`src/pages/signage/themes/gilded/` を新設し、default 配下のコンポーネントを import しない。テーマは「丸ごと差し替え可能」が仕様であり、テーマ間のコード共有は片方の変更がもう片方を壊す結合を生む。共有してよいのはドメイン層(`src/domain/format`, `src/domain/timer` 等)と共有サイネージ層(`../events`, `../preload`, `..` の型)のみ。等幅数字表示のような小さなユーティリティは gilded 内に持つ。

代替案: default の画面を props で色替え → テーマ = 見た目一式の差し替えという仕様の趣旨に反するため不採用。

### D2: 演出は CSS ベースの全画面オーバーレイ 1 コンポーネント

`GildedEffectOverlay` が 4 イベント(tournament-start / in-the-money / heads-up / champion)を 1 つの CSS 演出パターン(ゴールドの帯 + イベント名のタイポグラフィ + 装飾罫 + シャイン)で表示し、イベントごとに文言だけ変える。動画素材を宣言しないため先読み・fetch は発生しない(仕様「宣言に無い素材を取得しない」に適合)。

タイミング(通常時):

- 0ms: オーバーレイのフェードイン + 装飾展開開始
- 2,000ms: 進行の合図 `onAdvance`(tournament-start = タイマー起動 / champion = タイマー停止・優勝画面へ)
- 5,000ms: フェードアウト完了、`onDone`

`prefers-reduced-motion` 時は展開アニメーションを省き、フェードのみで 0ms 合図 / 1,500ms 終了。タイマー(setTimeout)は effect クリーンアップで必ず解除する。標準テーマの「7 秒」は動画尺由来の値であり、CSS 演出の GILDED は独自に 2 秒と定める(合図時刻はテーマの決定事項)。

### D3: assets 宣言は空(初期)

初期は素材を一切配置しないため `SignageTheme` の `assets` を省略する(宣言 = 実配置のみ、が既存規約)。効果音は共有層が `themes/gilded/sounds/<イベント名>.ogg` を試行し、未配置なら無音スキップされる(既存挙動)。後日素材を置く際に assets.ts へ列挙を追加する。`effectTimeoutMs` は既定 20 秒のままで十分(演出は最長 5 秒)。

### D4: レイアウトは 1920×1080 ステージ + scale フィット

default と同じ手法(1920×1080 の固定ステージを `Math.min(vw/1920, vh/1080)` で scale)を採る。タイマー画面のスケーリング要件を確実に満たし、16:9 前提のデザインを崩さないため。

### D5: ビジュアル言語(Claude Design モック準拠)

- 地: 深いグリーン(#08110E / #050b08 / #071411 系)+ ラジアルグラデーション。ポーカーテーブルのフェルトを想起させる
- 金: #B8862F / #C9A44C 系の罫・ラベルと、background-clip による金グラデ文字(CHAMPION 等)
- 罫・フレーム: 待機画面は 22px インセットの金枠 + 四隅の段状装飾、クロック画面は金罫によるヘッダー / 3 カラム / フッターの分割
- フォント: Big Shoulders Display(待機)/ Bebas Neue + Oswald(クロック)/ Anton(優勝)を Google Fonts に追加し、和文は Noto Sans JP へフォールバック

### D6: レベルアップ / 一時停止演出(クロック画面内)

- タイマーとブレイクは同一レイアウト(ClockScreen)で表示し、バッジ(LEVEL nn / BREAK)と主カウントダウンだけ切り替える。ブレイク中は次に始まるブラインドを主表示にする
- レベルアップ: 「LEVEL UP」の金文字をカウントダウンに重ねてフェード表示し、バッジ・ブラインド値を縦ロールで切り替え、背景を一瞬明るくする
- 一時停止: 画面を暗転し金罫のバンド(一時停止アイコン + PAUSED)をオーバーレイ表示(デザインモック Pause Overlay 準拠)。タイマー画面・ブレイク画面の両方に出す(MUST)
- 残り 60 秒以下でカウントダウンを金色の警告表示にする
- いずれも `prefers-reduced-motion` でフェードのみに簡易化

### D7: 優勝画面の背景画像

優勝画面の背景画像は `public/themes/gilded/images/champion.png` を置くと表示される(default テーマと同じ任意素材方式)。未配置なら深緑の地のまま成立する。配置したら assets 宣言に追加して先読み対象にする。

## Risks / Trade-offs

- [CSS 演出は動画に比べ豪華さで劣る] → アール・デコの静的な装飾・タイポグラフィで質感を担保し、将来動画素材を配置したくなったら assets 宣言 + オーバーレイの差し替えで対応できる構成にする
- [default とのコード重複(スケーリング・等幅数字等)] → テーマ独立性を優先した意図的な重複。共通化は 3 テーマ目が見えてから検討する
- [長時間表示での負荷] → アニメーションは演出中のみ動かし、常時動くものは CSS の緩やかなシャイン程度に留める(transform / opacity のみ使用)
