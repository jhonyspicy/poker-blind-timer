# signage-display 差分: GILDED テーマの追加

## ADDED Requirements

### Requirement: GILDED テーマの表示と演出実装

サイネージは、選択可能なテーマとして GILDED(id: `gilded`、深いグリーン×ゴールドのアール・デコ調)を提供しなければならない(MUST)。GILDED は待機 / タイマー / ブレイク / 優勝の各局面を専用画面として表示し、タイマー画面の表示項目・K 表記・レベルアップ / 一時停止演出・待機画面の表示内容などテーマ共通の要件をすべて満たさなければならない(MUST)。

GILDED の演出(トーナメント開始・インマネ・HEADS UP・優勝)は CSS アニメーションで実装し、動画素材に依存してはならない(MUST NOT)。動画素材を宣言しないため、動画ファイルへの取得要求を行ってはならない(MUST NOT)。

GILDED は演出の表示開始から **2 秒後**に進行の合図を返し、5 秒以内に終了を返さなければならない(MUST)。`prefers-reduced-motion` が有効な場合はフェードのみの簡易表示とし、表示開始と同時に合図を返すべきである(SHOULD)。

効果音は共有層の仕組みに従い `themes/gilded/sounds/` 配下の配置済み素材のみ再生する(未配置は無音でスキップ。既存仕様どおり)。

#### Scenario: GILDED テーマでの表示

- **WHEN** テーマに GILDED を選択した設定でサイネージを開く
- **THEN** GILDED の画面一式(深いグリーン×ゴールドのデザイン)で表示され、タイマー画面には共通要件の全項目が表示される

#### Scenario: GILDED の開始演出

- **WHEN** GILDED テーマでリモコンから開始操作を受信する
- **THEN** CSS の開始演出がオーバーレイ表示され、表示開始から 2 秒後にタイマー画面へ遷移してカウントダウンが始まり、演出は 5 秒以内に終了する

#### Scenario: GILDED は動画素材を取得しない

- **WHEN** GILDED テーマでサイネージを開き、トーナメントを進行させる
- **THEN** 動画ファイルへの取得要求は行われず、演出はすべて CSS で表示される
