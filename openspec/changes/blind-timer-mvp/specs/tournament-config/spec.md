# tournament-config: トーナメント設定(エディタ)

## ADDED Requirements

### Requirement: ストラクチャーの定義
エディタ画面(`/editor`)は、トーナメントのストラクチャーをレベル単位で定義できなければならない(MUST)。各レベルには以下を設定できる:

- スモールブラインド(SB)
- ビッグブラインド(BB)
- アンティ(Ante)
- そのレベルの継続時間(分)

また、レベルの並びの任意の位置にブレイク(休憩、継続時間つき)を挿入でき、レイトレジストレーション締め切り位置を指定できなければならない(MUST)。

#### Scenario: レベルの追加と編集
- **WHEN** ユーザーがレベルを追加し、SB=100 / BB=200 / Ante=200 / 継続時間=20 分を入力する
- **THEN** ストラクチャー一覧に入力どおりのレベルが表示される

#### Scenario: ブレイクの挿入
- **WHEN** ユーザーがレベル 4 とレベル 5 の間にブレイク(10 分)を挿入する
- **THEN** ストラクチャー一覧の該当位置にブレイクが表示される

#### Scenario: レイトレジストレーション締め切りの指定
- **WHEN** ユーザーがレイトレジストレーション締め切りをレベル 6 終了時に設定する
- **THEN** 設定に締め切り位置が保存され、一覧上に締め切り位置が明示される

### Requirement: トーナメント情報の設定
エディタ画面は、以下のトーナメント情報を設定できなければならない(MUST):

- お店の名前
- トーナメントタイトル
- プライズ(賞金)一覧(順位と内容)
- スターティングスタック(エントリー時に配られるチップ量)
- アドオン / リバイの設定(可否)
- アドオンのチップ量(アドオン可の場合)

スターティングスタックとアドオンのチップ量は、サイネージがエントリー / アドオンを履歴に記録する際のデフォルトのチップ量として使用される。

#### Scenario: 基本情報の入力
- **WHEN** ユーザーが店名・トーナメントタイトル・プライズ一覧・スターティングスタックを入力する
- **THEN** 入力内容が設定として保持される

### Requirement: 設定の保存と再利用
エディタ画面は、設定を IndexedDB に保存しなければならない(MUST)。保存済み設定は一覧から選択して読み込み・編集・削除ができ、繰り返しのトーナメント運営で再利用できなければならない(MUST)。

#### Scenario: 設定の保存
- **WHEN** ユーザーが設定を保存する
- **THEN** 設定が IndexedDB に永続化され、ブラウザをリロードしても失われない

#### Scenario: 保存済み設定の再利用
- **WHEN** ユーザーが保存済み設定の一覧からひとつを選択する
- **THEN** その設定がエディタに読み込まれ、編集・再保存できる

#### Scenario: 設定の削除
- **WHEN** ユーザーが保存済み設定を削除する
- **THEN** 一覧から該当設定が消え、IndexedDB からも削除される

### Requirement: 設定の検証
エディタ画面は、タイマーとして成立しない設定の保存を防がなければならない(MUST)。少なくとも以下を検証する: レベルが 1 つ以上存在すること、SB/BB/継続時間が正の数であること、スターティングスタックが正の数であること、アドオン可の場合はアドオンのチップ量が正の数であること。

#### Scenario: 不正な値の拒否
- **WHEN** ユーザーが継続時間 0 分のレベルを保存しようとする
- **THEN** エラーが表示され、保存されない
